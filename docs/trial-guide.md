# 天机阁小范围试用指南

本指南用于第七阶段小范围试用。目标是验证当前核心业务链路是否稳定、权限是否真实、页面是否能让各角色看懂并完成自己的工作。

## 试用入口

- 前端入口：http://localhost:3000
- 登录页：http://localhost:3000/login
- 法旨中心：http://localhost:3000/dashboard/fazhi
- 操作日志：http://localhost:3000/dashboard/logs
- 后端健康检查：http://localhost:3001/api/health

## 测试账号

| 角色 | 账号 | 密码 | 主要测试目标 |
| --- | --- | --- | --- |
| 管理员 | `admin` | `admin123` | 全局可见、全局统计、所有页面入口、操作日志 |
| 运营 | `operator` | `operator123` | 创建法旨、编辑草稿/退回需求、提交运营主管审批、查看设计结果 |
| 运营主管 | `leader` | `leader123` | 审批通过、退回运营需求、查看已审批需求 |
| 设计主管 | `dm` | `dm123` | 查看运营通过需求、分配设计师、设计审核通过/退回 |
| 设计师 | `designer` | `designer123` | 查看自己任务、开始设计、上传完成稿、提交审核、处理退回 |

## 推荐完整试用流程

1. 使用 `operator / operator123` 登录。
2. 进入法旨中心，新建一条法旨。
3. 填写主单基础信息，设置需求张数，检查图片任务是否生成。
4. 在图片任务中填写图片用途、需求类型、修改要求、原图/参考图链接。
5. 上传或填写主单附件、图片任务附件。
6. 提交运营主管审批。
7. 使用 `leader / leader123` 登录。
8. 在仪表盘或法旨中心找到待审批法旨。
9. 先测试退回，填写退回备注。
10. 使用 `operator` 登录，确认能看到退回备注，并能继续编辑。
11. 再次提交运营主管审批。
12. 使用 `leader` 登录并审批通过。
13. 使用 `dm / dm123` 登录。
14. 确认只能看到运营主管审批通过后的法旨。
15. 给图片任务分配 `designer`。
16. 使用 `designer / designer123` 登录。
17. 确认只看到分配给自己的图片任务。
18. 将任务改为设计中，上传完成稿，填写设计备注。
19. 提交设计审核。
20. 使用 `dm` 登录，测试退回修改并填写审核备注。
21. 使用 `designer` 登录，确认可看到退回任务，修改备注或重新上传完成稿后再次提交审核。
22. 使用 `dm` 登录，审核通过。
23. 使用 `operator` 登录，确认能查看设计审核结果、审核备注和完成稿附件。
24. 使用 `admin` 登录，检查全局可见、操作日志、角色化仪表盘。

## 各角色重点检查项

### ADMIN

- 仪表盘显示全局统计和全部待办。
- 法旨中心可以看到全部法旨。
- 操作日志页面可以访问，能看到操作人、时间、类型、对象和摘要。

### OPERATOR

- 仪表盘聚焦自己的草稿、被退回、待审批、已通过需求。
- 只能编辑自己创建且处于草稿或运营主管退回状态的法旨。
- 不能审批运营需求。
- 不能分配设计师。
- 不能执行设计审核。

### OPS_MANAGER

- 仪表盘聚焦待审批、已审批、已退回需求。
- 可以审批通过或退回运营提交的法旨。
- 不能分配设计师。
- 不能执行设计审核。

### DESIGN_MANAGER

- 仪表盘聚焦待分配、设计中、待设计审核任务。
- 只能看到运营主管审批通过后的法旨。
- 可以分配设计师。
- 可以审核通过或退回设计师提交的图片任务。
- 不能审批运营提交。

### DESIGNER

- 仪表盘只显示分配给自己的图片任务。
- 不能看到未分配给自己的图片任务。
- 不能看到运营主管未审批通过的任务。
- 可以开始设计、上传完成稿、填写设计备注、提交审核。
- 可以处理退回任务并重新提交。
- 不能审核自己的任务。

## 权限边界重点验证

- OPERATOR 调用运营主管审批接口应被拒绝。
- DESIGNER 查看运营主管未审批通过的任务应被拒绝。
- DESIGN_MANAGER 在运营主管审批前分配设计师应被拒绝。
- OPERATOR 分配设计师应被拒绝。
- DESIGNER 操作未分配给自己的图片任务应被拒绝。
- DESIGN_MANAGER 审核未提交审核的图片任务应被拒绝。
- DESIGNER 审核自己的任务应被拒绝。
- DESIGNER 给未分配任务上传完成稿应被拒绝。

## 通过标准

- 五个账号均可登录。
- 每个角色仪表盘看到的统计卡片和待办不同。
- 法旨中心状态均显示中文。
- 法旨详情能显示主单信息、附件、图片任务、设计备注、审核备注。
- 完整法旨流转能从创建走到设计审核通过。
- 操作日志能记录关键动作。
- 页面无 404，空数据时有明确提示。
